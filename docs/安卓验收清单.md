# Android 客户端验收清单

> 背景：开发环境没有安卓设备，APK 只验证了「能构建、元数据正确、原生库齐全」。
> 这份清单是给你拿到手机后 5 分钟能做完的验收步骤。
>
> 安装包：`dist/RiJi-Android/RiJi-日记-arm64.apk`（老机型用 armv7，不确定用"通用"）

## 装之前：让手机能连上电脑

1. 在**运行服务端的电脑**上，启动前设 `set RJJ_HOST=0.0.0.0`（默认只听 127.0.0.1）。
2. Windows 防火墙放行 8080 端口。
3. 查电脑的局域网 IP：命令行执行 `ipconfig`，找 `IPv4 地址`（形如 `192.168.1.10`）。
4. 手机和电脑连**同一个 Wi-Fi**。

## 六项检查

### 1. 能安装

点开 APK → 允许"未知来源" → 安装完成，桌面出现**日记**图标。

**通过标准**：图标是应用名"日记"，不是 `riji_client`。
**失败时**：安卓 8 以上可能在"安装未知应用"权限里需要单独授权当前文件管理器。

### 2. 能登录

打开 App → 服务器地址填 `http://电脑IP:8080` → 输入账号密码 → 登录。

**通过标准**：进入主页，看到"可写窗口"和"最近日记"。
**失败时**：
- 一直转圈 → 服务器地址错或不在同一网络
- 提示"用户名或密码错误" → 密码错（注意安卓输入法可能自动加空格）

### 3. 自检全绿

主页右上角菜单 →「自检（检查是否可用）」。

**通过标准**：
- 服务器连通 ✓
- 登录状态 ✓
- 端到端加密 ✓
- 同步队列 "没有待推送内容" ✓
- 本地缓存 ✓
- PDF 导出字体：**安卓上大概率是"提示"**（系统字体路径与 Windows 不同），这不影响使用

**失败时**：页面上每项下面都写了"建议"，照着做。

### 4. 能写日记并自动保存

点"写今天" → 打一段字 → 等 1 秒多。

**通过标准**：右上角出现"已保存 HH:MM"（不是"保存失败"）。
返回主页，今天那张卡片显示"1 个块"。

### 5. 能录音并插入

编辑器工具栏点"语音" → 系统弹麦克风权限 → 允许 → 录 3 秒 → 停止并插入。

**通过标准**：
- 出现一个语音条，显示 `00:00 / 00:03`
- 点播放键能听到自己刚才的声音，进度条前进

**失败时**：
- 没弹权限 → 去系统设置手动开麦克风
- 录完没有声音 → 检查是否被其他 App 占用麦克风

### 6. 断网也能写，联网自动同步

开飞行模式 → 写一句话 ~ 等出现"已保存到本地，联网后自动同步" → 关飞行模式。

**通过标准**：
- 断网时内容不丢（返回再进入还在）
- 联网后点「立即同步」，进度提示消失，内容出现在另一台设备（比如 Windows 客户端）上

## 进阶：多设备一致性

在 Windows 客户端上打开同一天的日记，确认手机写的内容出现在里面。
再在 Windows 上改一句，回到手机下拉刷新/点同步，确认手机也变了。

## 已知限制（不是 bug）

| 现象 | 说明 |
|---|---|
| 自检里"PDF 导出字体"是黄色提示 | 安卓字体路径不同，PDF 中文可能显示方块；其他三种导出格式不受影响 |
| 不能选 127.0.0.1 | 那是指手机自己，必须填电脑的局域网 IP |
| 应用不会上架应用商店 | 直接装 APK，需要允许未知来源 |

## 如果出问题

把这三样发我，基本能定位：

1. 自检页截图
2. 手机浏览器访问 `http://电脑IP:8080/healthz` 的显示内容
3. 电脑上服务端窗口最后 20 行日志
