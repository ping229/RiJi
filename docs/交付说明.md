## 一、三分钟开始用

### Windows

1. 解压 `dist/RiJi-Windows-x64.zip` 到任意目录（不要放在系统盘的 `Program Files`）
2. 双击 `riji_client.exe`
3. 服务器地址填 `http://127.0.0.1:8080`，输入用户名密码

如果服务端还没起来：回到项目根目录，双击 **`安装.bat`**，它会自动装环境、建库、启动服务端、创建桌面快捷方式。

### 安卓

1. 把 `dist/RiJi-Android/RiJi-日记-arm64.apk` 传到手机
2. 安装（允许"未知来源"）
3. 服务器地址填**电脑的局域网 IP**，例如 `http://192.168.1.10:8080`

> 不能用 `127.0.0.1`——那指的是手机自己。手机和电脑要在同一个 Wi-Fi。

详细步骤见 `dist/RiJi-Android/安装说明.txt` 和 [安卓验收清单.md](安卓验收清单.md)。

## 四、没有验证过的部分

我必须明确列出来，这些不是"肯定有问题"，而是"我没能证明它没问题"。

| 项 | 原因 | 影响 |
|---|---|---|
| **安卓真机运行** | 开发环境没有安卓设备，模拟器需要管理员权限开 Hyper-V | APK 能构建、元数据正确、原生库齐全，但没有在真实手机上跑过一次 |
| Docker 镜像构建 | 本机 Docker 守护进程无法启动（缺 WSL 发行版） | `docker-compose.yml` 通过语法校验，服务端按容器同款环境变量实跑通过，但镜像没 build 过 |

| 富文本/波形的视觉效果 | GUI 自动点击不可靠 | 逻辑有测试，绘制代码通过编译，但没有截图佐证"好不好看" |
| 多设备长期并发 | 只有两节点短时验证 | 长时间高频并发下的表现未知 |

## 五、数据与安全

### 数据存在哪

| 情况 | 位置 |
|---|---|
| 正常 | `%APPDATA%\RiJi` |
| 系统拒绝写 AppData | 程序同目录的 `data\`（自动回退并迁移） |

客户端「自检」页顶部会显示**实际路径**，旁边有「打开数据目录」按钮。

### 加密保护什么

| 场景 | 是否受保护 |
|---|---|
| 服务器被入侵、数据库被拖走 | ✅ 只有密文 |
| 管理员偷看 | ✅ 接口层没有入口，数据本身也是密文 |
| 数据库备份泄漏 | ✅ 只有密文 |
| 电脑被别人用（已登录状态） | ❌ 客户端能直接解密 |
| 本机磁盘被拆走 | ❌ 本地缓存是明文 |
| **忘记密码且没设恢复短语** | ❌ 数据永久无法解密 |

最后一条是端到端加密的固有代价，不是缺陷。**强烈建议**：登录后去菜单「恢复短语」，抄 16 个词在纸上。

### 备份

```powershell
# 数据库
pg_dump -h 127.0.0.1 -p 5544 -U diary riji > riji.dump
# 媒体
robocopy server\var\media D:\backup\media /E
```

密文备份即可——没有主密钥的人拿到备份也读不出内容。

## 六、常见问题

**Q：手机连不上电脑**
A：三件事依次检查：① 同一 Wi-Fi；② 手机浏览器打开 `http://电脑IP:8080/healthz` 能看到 `{"status":"ok"}`；③ Windows 防火墙放行 8080。

**Q：导出的 PDF 中文是方块**
A：系统缺中文字体。自检页会提示。其他三种导出格式（HTML/Markdown/ZIP）不受影响。

**Q：日记突然"不见了"**
A：先看自检页的数据目录路径，确认程序读的是不是你预期的位置。数据不会自己消失，多半是路径变了。

**Q：改密码后其他设备登录不上**
A：这是设计如此。改密码会让所有设备的登录态失效，重新登录即可，日记内容不受影响。

**Q：粘贴进来的文字排版乱了**
A：在输入框里右键，选「粘贴并清理格式」。
